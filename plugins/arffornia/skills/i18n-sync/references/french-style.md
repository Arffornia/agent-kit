# French for Arffornia players

- Register: `vous` on the website and launcher; in game, short imperatives ("Sélectionnez une
  recette"). Keep one register per surface.
- Typography: a no-break space (U+00A0, or narrow U+202F) before `:` `;` `?` `!` `»` and after
  `«`. Use `«  »` for quotes in prose, `'` → `'` (typographic apostrophe) where the font
  supports it (the vanilla Minecraft font does).
- Capitals: sentence case for buttons and titles ("Mes récompenses", not "Mes Récompenses").
- Numbers: `1 000` (no-break space thousands separator), decimal comma `2,5`, `%` preceded by
  a no-break space. Format numbers with the locale, never by string concatenation.
- Length: French is about 20-30% longer. In GUI keys prefer the short form ("Énergie", "Prog.")
  and flag anything over 1.3x English for the UI check.
- Minecraft vocabulary as the French client says it: Établi (crafting table), Four (furnace),
  Coffre, Lingot de fer, Bloc, Objet, Inventaire, Succès (advancements), Équipe. Mod names stay
  as published (Applied Energistics 2, Create).
- Arffornia terms: milestone = jalon, stage = palier, progression = progression, shop =
  boutique, vote = vote, reward = récompense, Crafter = Crafter (proper noun), Space Elevator
  = Ascenseur spatial.
- Never translate placeholders, key names, commands (`/arffornia shop claim_reward`) or
  formatting codes (`§a`).
