# architecture/arffornia workflow and conventions

## Layout of the docs repo

| Path | What |
|---|---|
| `architecture/arffornia/model.yaml` | every element, connection and reference; header comment lists the source commits it was derived from |
| `architecture/arffornia/views/<id>.yaml` | one diagram each: runtime, content-delivery, player-login, vote-and-reward, previews, tech-stack |
| `architecture/arffornia/layouts/<id>.yaml` | positions for topology views (runtime, content-delivery, previews) |
| `architecture/arffornia/discovered/k8s-*.yaml` | generated by `make discover`; never edited by hand |
| `docs/architecture/<id>.md` | the page embedding `docs/assets/diagrams/<id>.<theme>.png` / `.drawio.svg` |
| `scripts/discover.sh` | overlays → fragments (dir:namespace pairs) |

## Conventions of this model

- Header comment of `model.yaml`: update the "Derived from code, <date>" line and the commit
  of every repo you read (`infra@<sha>`, `Arffornia_Mods@<sha>`...). Each view's `meta` has
  the same scope line; update it for views you change.
- Regions: TEAM, PLAYER PC, INTERNET, CLOUDFLARE, HOME NETWORK, NAS, KUBERNETES · HOMELAB,
  GITHUB, DOWNLOADS, MICROSOFT · MOJANG, THIRD-PARTY SAAS. New elements go into one of them.
- Namespaces are `group` elements that `matches` the discovered namespace id
  (`k8s:<ns>/namespace/<ns>`); workloads match their Deployment/StatefulSet and Service.
- Each topology view has a "Gaps and risks found in code" card (`card-gaps`): when code and
  docs disagree, draw the code, add the gap there with both sources.
- Arrows: client → server, requests only, label `[step] verb · protocol`, port on the
  server's badge. Flows that go back and forth (login, token exchange) are `type: sequence`
  views (player-login, vote-and-reward).
- Never put secret values, internal IPs beyond what is already public in the model, or
  exploit details of unfixed weaknesses (public repo).

## Review checklist

- [ ] `drift.py`: no `GONE`; every `UNMATCHED` either modelled or listed as out of scope in a
      view's `meta`.
- [ ] `CHECK_ONLY=1 export.sh` and `make check` green.
- [ ] PNGs looked at, dark and light; nothing cropped (pageWidth vs the 3900 px cap).
- [ ] The page in `docs/architecture/` still describes the diagram; facts from code cite
      `repo@sha path:line`.
- [ ] Commit contains YAML and regenerated exports together.
